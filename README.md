# PokeBattles

A Pokémon UNITE-style browser game in a single HTML file. Battle in real time on several maps (3v3, 4v4, and a special 10v10 Volcano), earn gems, and buy Pokémon, Mega Pokémon and skins in the Shop.

## Play
Open `index.html` in a desktop browser (Chrome, Firefox, Edge or Safari) while online. Pokémon data and sprites load live from [PokeAPI](https://pokeapi.co).

## Controls
- Move: WASD or arrow keys
- Attack: J, Space or click
- K and L: your Pokémon's two type powers
- U: Unite move (when the meter is full)
- I: Potion (you get one every match; heals 25% of your health, 15-second cooldown)

## Also in the game
- Missions tab: finish missions for gems; every 5 missions raises your reward path one level (resets every 5 days).
- Standing in your own base heals you. The Unite meter fills 5% every second. A win pays 15 gems, a loss 10, and a win gets a confetti shower (skipped if your system asks for reduced motion).
- Inventory: My items (Points Booster doubles battle points for 105 battles; each win has a 25% chance to drop one) and Save data (copy a code or download a file to move your progress).
